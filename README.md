# PREET PATEL - Terminal Portfolio

An interactive terminal portfolio for **Preet Patel**, a software development engineer focused on systems, compilers, backend platforms, and AI/RAG infrastructure.

🚀 **Live Demo:** [preet-patel-portfolio.vercel.app](https://preet-patel-portfolio.vercel.app/)


The portfolio is built with Svelte 4, TypeScript, Tailwind CSS, and Vite. Its primary interface is a responsive terminal with the prompt:

```text
preet-patel:~$
```

## About

The terminal presents Preet's education, experience, technical skills, achievements, projects, and engineering demonstrations through discoverable commands. It includes detailed work on the OptiLang compiler, ResearchPaper AI, an AI learning management system, and ransomware detection research.

## Features

- Interactive, responsive terminal interface with command history and Tab completion
- Custom `preet-patel:~$` prompt and PREET ASCII banner
- Profile commands for education, experience, skills, projects, and achievements
- Interactive OptiLang compiler benchmark and ResearchPaper AI RAG demos
- Resume access and GitHub, LinkedIn, and email integrations
- Theme switching with multiple built-in themes
- Todo management, safe arithmetic evaluation, unit conversion, weather lookup, and URL fetching
- Keyboard history navigation and `Ctrl+L` screen clearing
- Mobile-friendly layout preserving the terminal aesthetic

## Featured Projects

### Pre-Encryption and Identification of Crypto Ransomwares

**Status:** Ongoing Research

**Technologies:** OS, Cuckoo Sandbox, Python, Random Forest, SHA-256, RSA, MySQL

Designed a ransomware detection framework combining Random Forest classification and SHA-256 signature matching for early threat identification. Malware behavior is analyzed with Cuckoo Sandbox to extract behavioral features for classification.

### AI Learning Management System

**Technologies:** Next.js, Clerk, Drizzle ORM, Neon PostgreSQL, Google Gemini, Inngest

- Supports five course types, including exam preparation, job interviews, and coding practice, with structured JSON outlines generated by Google Gemini.
- Produces four study formats: chapter notes, flashcards, quizzes, and Q&A, with interactive learning interfaces.
- Uses four background Inngest functions across five REST API routes for asynchronous content generation and user synchronization.
- Uses Drizzle ORM with Neon Serverless PostgreSQL across an 11,000+ line codebase, with Clerk authentication and generation-status tracking.
- [View repository](https://github.com/patelpreet404-alt/ai-learning-management-system)

### ResearchPaper AI - RAG Document Q&A Platform

**Technologies:** Python, FastAPI, LangChain, FAISS, OpenAI Responses API, SQLite

- Clean Architecture pipeline across eight modular services with 1,000-character chunks and 150-character overlap.
- Persistent FAISS semantic retrieval, SQLite-backed multi-turn memory, and structured OpenAI Responses API output.
- Token-by-token Server-Sent Events with page-level citation tracing across a 4,871-line FastAPI codebase.
- Offline-runnable pytest suite with 10 tests across six files, plus ruff linting and mypy type-checking.
- [View repository](https://github.com/patelpreet404-alt/researchpaper-ai)

### OptiLang - Mini Compiler

**Technologies:** C++17, Flex, Bison, LALR(1) Parsing, LLVM IR, Compiler Optimization

- 3,786-line, eight-stage compiler pipeline covering lexing, LALR(1) parsing, semantic analysis, TAC generation, optimization, and LLVM IR emission.
- Five optimization passes, including constant folding/propagation, common subexpression elimination, dead code elimination, unreachable block elimination, and LICM.
- 35% instruction reduction from 57 to 37, 41% non-label instruction reduction from 27 to 16, and 0.34ms average optimizer runtime across five benchmark runs.
- Clang LLVM IR backend with `-O3` comparison and a 12-test CI suite covering compilation, error detection, and CLI flags.
- [View repository](https://github.com/patelpreet404-alt/OptiLang)

## Getting Started

### Requirements

- Node.js `>=18.17.0`

### Install and Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in a browser. The port is configured in `vite.config.ts` and reused by the Playwright E2E setup.

## Design Philosophy

The portfolio keeps the interaction model intentionally focused: a familiar terminal surface, readable command output, keyboard-first navigation, persistent history, and theme support. Personal information is exposed through small, composable command modules so profile content remains easy to inspect and maintain without changing the core terminal experience.
